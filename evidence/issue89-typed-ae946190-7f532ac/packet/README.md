The authorized caller must start it directly with **exactly** an independently reviewed clean environment and isolated flags, e.g. `/usr/bin/env -i PATH=/usr/bin:/bin LANG=C.UTF-8 /usr/bin/python3 -I -S -B /absolute/trusted/bootstrap.py --packet ... --manifest ... --manifest-sha256 ... --ack ... --ack-sha256 ...`.
