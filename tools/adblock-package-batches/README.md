# Source-first adblock package batches

This experimental runner separately compares the `adblock-fast` service and `luci-app-adblock-fast` app using the two frozen source-first oracles. It is independent of the existing luci-base workflow. No invocation or package result follows from this code. Reconcile the existing run, then review and freeze exact final code, oracles, commands, config and source pins before any manual dispatch.

The runner uses one fresh Linux environment and serially builds the service, snapshots and compares its raw IPK, builds the app, checks the service archive and stage again, and compares the app. It retains each command's timing and each raw archive; CI unit tests do not launch builds. The comparator strictly enumerates data and control archives without extracting, compares package-specific identities and complete stage files, records source, prepared (app), stage and IPK hashes/modes, and requires recipe-projected source/control identities. The service's 0600 config, 0755 init/defaults, and version substitution are separate from the app's direct root copies. If JS minification is enabled, output provenance is unresolved even when stage and IPK bytes match; if disabled, equality with source is required. Source projections do not establish root-image installation, execution, reachability, semantic analysis or security.

Local checks: `python3 -B -m unittest discover -s tools/adblock-package-batches -p 'test_*.py' -v`, `python3 -B -m unittest discover -s tools/luci-base-inventory -p 'test_*.py' -v`, `for script in tools/adblock-package-batches/{run,batch-order,locate-paths}.sh; do bash -n "$script"; done`. The run requires `CONFIG_PER_FEED_REPO=y` and searches the per-feed output tree. A fresh run requires exact pinned sources, successful config/feed preflight, safe unique output paths and both independently reviewed package oracles. Failures or unexpected members need investigation; do not relax checks automatically or reuse an invalid attempt.
