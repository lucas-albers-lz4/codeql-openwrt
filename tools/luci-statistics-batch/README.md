# Statistics-only build guards (pre-dispatch candidate)

This is an offline-reviewed candidate under development, not a dispatched build or package receipt. It pins the independently reviewed [source-first oracle](source-oracle.json) for LuCI `cb87fe60e1e2e052af36a93647f2264577829e0a` and a Statistics-only metadata run: final config SHA-256 `cbff738c953271533651885c3759d6a5ba6b845c61b23a1e7aca7059f552d8ff`, `.packagedeps` SHA-256 `48bbf0a4525d53718fb8271f52857082e7917b09c268873706261b897ecf3b69`. The config selects base and Statistics and explicitly disables Dockerman and both minifiers. The three source pins, feeds and diagnostic scope come from the reused metadata probe. No metadata or build command is authorized by this file; exact-head independent review and an explicitly approved execution context must precede any run.

The candidate `run.py` uses the metadata probe in a fresh physical Linux run root, retains the config and graph before and after each timed normal Make command, checks pinned source/consumer and feed links, and runs tools, toolchain, `target/linux/compile`, `package/kernel/linux/compile`, then the Statistics target with two jobs. It records commands, output, elapsed time and GNU time peak RSS. Kernel compilation can produce `bzImage` and module artifacts, not a firmware/image installation. It inventories the unique kernel root's physical `.config`, `.modules`, built-in indexes, release and `.ko` files, requires x86_64 and the pinned 6.12.116 version, and checks inventory before and after the package target. The normal kernel package target evaluates its selected `FILES` against that actual kernel; missing-module errors and selected empty-package warnings stop the run, even if a command returns zero. It checks kernel `.vermagic` against the exact package version and staged `kernel.version`, inspects the virtual kernel IPK builtin metadata, retains that IPK and the small kernel source evidence, and rechecks the kernel IPK inventory and files after Statistics. The inventory is not a proof of device installation or runtime behavior.

The candidate retains a Statistics IPK and source/prepared/stage/IPK comparison receipt in the same run. Metadata `.packageinfo` and `.config-package.in` contain run-specific paths and are retained but are not compared byte-for-byte to the old host. Full stdout, stderr, timing, exact vector and postguard results are retained locally; unsafe or nonquiescent states fail closed. Final evidence needs independent audit and safe artifact packaging. A hosted job is ephemeral, so the kernel and toolchain must not be assumed reusable across jobs. The manual workflow is not run automatically. It requires Linux x86_64, two CPUs, at least 8 GiB total RAM and 60 GiB free disk, and permits tools 60 minutes, toolchain 80, kernel compile 90, kernel packages 60 and Statistics 40, within a 360-minute hosted job. The earlier tools/toolchain measurements (~12/~23 minutes) give context; kernel/dependency time is unmeasured, so these are bounded limits, not completion estimates. The Make limits total 330 minutes, leaving at most 30 minutes for metadata, retention and upload if every limit is approached. A timeout can prevent final artifact upload. The 512 MiB portable USTAR cap intentionally withholds unsafe, nonquiescent or oversized evidence; raw files then remain only on the ephemeral host and may be lost. The manual workflow installs the same host prerequisite package list as the earlier #186 workflow; its timed apt output is copied into the evidence after success. An apt failure before runner initialization is visible in the hosted job log but cannot be included in the manifest-validated artifact.

`compare.py` is an offline comparator component for that future continuation. It requires physical run-owned directories, disabled minifiers, exact 126 source projections, control identity, archive-wide strict parser, and separate source/prepared/stage/IPK byte and mode evidence. Its synthetic tests use a real strict parser and 126-member staging trees. It is not a package result: the Statistics IPK and build stage have not been inspected or produced here. The source-first projection does not prove runtime, installation, authorization or security.

Run offline controls without network or Make:

```sh
python3 -I -B tools/luci-statistics-batch/run.py --help
python3 -I -B tools/luci-statistics-batch/package.py --help
python3 -B -m unittest discover -s tools/luci-statistics-batch -p 'test_*.py'
python3 -O -B -m unittest discover -s tools/luci-statistics-batch -p 'test_*.py'
```
