# Experimental typed setBlockDetect handoff

The real-run entrypoint requires `--reviewed-context` and the externally reviewed context digest. No real paired run is approved merely by supplying the flag or digest. A concrete context and its adapter need separate independent pre-execution review, and the runner itself needs independent review before any real use.

Run `python3 -B tools/typed_handoff/test_prototype.py` to exercise a synthetic twelve-stage sequence using the retained source and typed-family oracle, two independently initialized Git worktrees, two report targets and a directory-shaped database. The test checks targeted failures including wrong Git pin, input drift, family-oracle changes, hardlinks, symlinks, path aliases, failing commands, corrupted streams and BQRS, altered diagnostics/effects state, duplicate report keys, non-log database mutation, packet omissions/additions, boolean inventory sizes, and optimization mode. These synthetic commands do not execute CodeQL or the actual policy importer.

The prototype records stage commands, environments, snapshots and streams; preserves source, lock and complete report bytes at the observed boundaries; checks exact typed-family rows before export/import; and compares reimport state. An independent offline reader checks frozen context and oracle bytes supplied with external digests, retained implementation bytes, receipt continuity, exact packet inventory and report transitions. Input, implementation and executable digests are bound to the frozen context. The operator-supplied digest is a comparison, not proof of independent review.

The runner does not sandbox subprocesses. Captured inventories describe selected state; they cannot establish that no transient or external writes occurred. Receipts and hashes do not authenticate execution, establish loaded-pack provenance, or prove runtime reachability, policy correctness, security, or completeness. The offline verifier does not re-evaluate BQRS semantics; a coherently forged packet is outside its guarantees. Use disposable inputs without secrets, and preserve the independent review and actual context outside the packet.

Before real use, finish reviewing and hardening context and receipt schemas, output and dependency identities, isolated interpreter configuration, path and filesystem race behavior, failure evidence, and the actual CodeQL adapter. Freeze fresh producer, consumer, source, dependencies, commands, environments, exact file/diagnostic and report oracles, and absent paths; obtain a separate independent review of that exact context before execution. The entrypoint flag is not authorization to do so.
