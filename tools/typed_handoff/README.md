# Experimental typed handoff prototype

This is a synthetic prototype, **not approved for real paired runs**. It executes the twelve named stages from a context, snapshots selected paths, gates export and import on a supplied oracle, and records before, first-import and replay report bytes. `verify.py` is a separate offline reader and accepts the external context and oracle digests. Run `python3 -B tools/typed_handoff/test_prototype.py` for its synthetic integration and one negative control. These are not CodeQL, producer, consumer or policy evidence.

The external reviewed digest is an operator-provided comparison, not proof of independent review. The receipt and inventories do not authenticate execution, prove confinement, observe transient writes, or establish runtime reachability, policy correctness, security, or completeness. A command may write outside inventoried paths. No sandbox is provided. Do not use this prototype on a production checkout or a real handoff.

Before real use, implement and independently review strict family/schema and stage transition enforcement, clean pinned inputs and complete dependencies, explicit command/output bindings and semantic decoding, file identity/diagnostics checks, path and hardlink/alias confinement, exclusive writes and locking, first-report timing, exact stage output absence/creation, independent external runner/verifier digests, and synthetic targeted mutation controls. In particular the prototype does not prevent coherent changes to early consumer state and receipts, does not establish that CSV files are the decoded BQRS or that the typed file is the exporter output, and does not re-evaluate BQRS semantics. Hashes cannot authenticate a coherently forged packet. No concrete context for a real run has been reviewed.
